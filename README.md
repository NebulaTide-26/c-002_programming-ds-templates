### c-002_programming-and-data-structures —— C 语言程序设计基础 & 数据结构模板库

##### 包括：
1. 通用的 C 语言板子（对标 buaa 传源大一“程序设计基础”课程）
2. 以 C 语言实现的各种数据结构模板（对标 buaa 传源大一“数据结构”课程）
3. 其他工具性程序文件  

##### 特别说明：
1. 模板中用到了一些课上不常用的 C 语言标准库。因此使用模板函数时，请将所有 #include 复制到你的文件中，以免缺失某些库的导入！！！
2. 使用“DEV C++”打开c语言程序时，请将  
"工具-编译器选项-显示-<ID 27071 translation missing>"（以 DEV C++ 6.3 版本为例）  
取消勾选，以正常显示中文注释。
3. 使用“DEV C++”编译c语言程序时，若出现中文输出乱码，请勾选
"工具-编译选项-编译器-编译时加入以下命令"
并填写
"-fexec-charset=GBK"（去掉引号）
